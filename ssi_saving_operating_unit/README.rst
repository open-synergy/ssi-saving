=======================
Saving + Operating Unit
=======================

Glue module that adds Operating Unit support to the Saving module. Extends
``saving_account`` and ``saving_interest_computation`` with
``mixin.single_operating_unit``, so that saving accounts and their interest
computations can be scoped and restricted per operating unit.


Installation
============

This module depends on:

* ``ssi_saving``
* ``ssi_operating_unit_mixin``
